# TugasWeb-Pertemuan3-Katalog

[![BETA](https://img.shields.io/badge/status-BETA-yellow)](https://github.com/emojibanana/TugasWeb-Pertemuan3-Katalog)

Ini adalah Katalog buku buku khusus yang saya masukkan berbasis HTML dan CSS (Tailwind via CDN). Situs ini berisi beberapa cover buku dengan harga yang dibuat-buat.

## Apa Isi nya?

- satu halaman katalog sederhana
- Navigation pakai anchors
- Kategori Buku yang bisa dipilih (BELUM BISA!)
- Tombol detail buku (BELUM ADA!)
- Tailwind CSS (via CDN)

## Kekurangan/Lagi Dikerjain

- Elemen formulir hanya placeholder (tanpa backend)
- Kategori belum bisa
- href header masih kosong
- Isi detail masi cihuyy
- Buku masih asal-asalan
- Besar masing masing buku masih tidak sinkron
- animasi yang kurang nyaman
- Penyempurnaan gaya diperlukan untuk visual yang lebih mantap

## Rencananya

- Buku yang lebih "Normal"
- Tombol Beli
- Tambah Footer
- Desain visual yang modern dan bersih
- Peningkatan aksesibilitas
- Optimasi kinerja
